# NOW

> 总看板只列任务和方向，不写具体安排。每个任务的目标、截止、▶ 下一步和卡点都只写在它自己的 `collab/PROGRESS.md`，看板从那里自动读取。
> 更新于 {{日期}}

## 索引

- **[看板.html](NOW/看板.html)**：可视化总览，「今天」和「任务」两个标签页，双击打开
- [今天](NOW/今天.md)：今天各时段做什么
- [本月布局](NOW/本月布局.md)：四周安排 + 本周三件事
- [已完成](NOW/已完成.md)：完成的任务从下表移到这里
- [截止](NOW/截止.md)：近期截止的来源（可在 `NOW/config.json` 改成别的文件）

改了任何相关 Markdown 后运行 `python3 NOW/build.py`；配好 Claude Code 的 Stop hook 后会自动生成。用常驻网页服务时把上面的看板链接换成网页地址，不再需要手动生成（见模板仓库 README）。

## 任务

状态只写 进行中 / 暂停。「分类」决定任务挂到哪个大方向，可选值见 `NOW/config.json`。完成后整行移到 [已完成](NOW/已完成.md)。
新任务：在任务目录运行 `~/.collab-templates/init.sh small`（或 `large`），再在下表加一行。

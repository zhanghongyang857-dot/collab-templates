# 协作协议

所有成员共用本协议。详细推理和执行过程留在各自的原生会话，公共文件只写结论、依据要点和位置。

## 文件与用途

| 文件 | 用途 | 何时读 |
|---|---|---|
| `../PROGRESS.md` | 唯一入口：现状、生效决议、进行中、待决、加载地图、日志 | 每次 |
| `协议.md` | 本协议 | 处理议题、任务、决议或收工时 |
| `成员.md` | 成员、所属应用、会话、默认角色 | 派发或验收时 |
| `决议.md` | 生效决议全文 | 任务卡引用或要改方向时 |
| `议题/I00x-*.md` | 需要多个成员分别发表观点的讨论 | 被点名时 |
| `任务/T00x-*.md` | 任务卡：交接、执行记录、验收 | 被点名时 |
| `经验.md` | 可复用的做法和坑 | 开始同类工作前 |
| `归档/` | 已关闭的议题和任务、被取代的决议、旧日志 | 查历史时，先搜索 |

## 基本规则

1. 只读加载地图要求的文件；需要历史时先搜索，再读命中部分。
2. 修改任何公共文件前重新读取它，只改属于自己的分区，不改写他人内容。
3. 讨论中的意见不是决议。只有用户确认后写入 `决议.md` 的才是。
4. 不确定的结果写「未知」或「未验证」，不能推断为完成。
5. 不在公共文件中粘贴大段过程、日志或代码，写位置即可。

## 写入规则

| 位置 | 谁写 | 方式 | 上限 |
|---|---|---|---|
| PROGRESS「现状」「进行中」 | 完成一步的成员 | 只改自己相关的行 | 现状 ≤5 行 |
| PROGRESS「▶ 下一步」 | 用户，或收工时代写 | 覆盖 | 1 条 |
| PROGRESS「生效决议」 | 写决议的成员 | 每条一行 | ≤8 条 |
| PROGRESS「待你决定」 | 任何成员 | 追加；只有用户删除 | — |
| PROGRESS「日志」 | 收工的成员 | 新的在上，一行一条 | 两周 |
| 议题各轮 | 对应成员 | 只追加，标明成员和轮次 | 每轮 ≤300 字 |
| 议题「裁决」 | 用户（可代写，需用户确认） | 填写一次 | — |
| `决议.md` | 用户说"定了"之后 | 新增条目，不改旧条目 | — |
| 任务卡「交接」 | 派发人 | 交接时填好；用户确认后不改 | — |
| 任务卡「执行记录」 | 只有执行者 | 追加 | 每条 ≤200 字 |
| 任务卡「验收」 | 只有验收者 | 追加 | 每条 ≤200 字 |
| `成员.md` | 用户 | 覆盖 | — |
| `经验.md` | 任何成员 | 一条一行 | ≤20 条，超出就合并 |

## 编号

- 议题 `I001`、任务 `T001`、决议 `D001`，各自递增，不复用。
- 新编号 = 在 `PROGRESS.md`、`协作/`、`协作/归档/` 中搜索到的最大编号 + 1。
- 新建议题或任务：复制对应目录下的 `_模板.md`，命名为 `编号-简短主题.md`，并在 PROGRESS「进行中」加一行。

## 状态

- 议题：开放 → 第1轮 → 第2轮 → 已裁决
- 任务：已交接 → 执行中 → 待验收 → 通过 / 需补充 / 未通过 → 已完成
- 任何时候可转为「受阻：原因」。
- 执行者开始工作时必须把状态改为「执行中」；不能不给结论就停止，结束时只能是「待验收」或「受阻」。
- 只有验收者能把任务改为通过；执行者自报完成不算通过。

## 独立判断

写议题第 1 轮前，只读「问题」部分，不看其他成员的观点。第 2 轮读全文并回应分歧。用户裁决后按决议执行，保留的异议可写在下一轮或新议题中。

## 原生会话记录

执行记录和决议来源中写明：`应用「会话名」日期`，例如 `Codex「T003 接口实验」10-18`。没有会话名时写能找到它的信息。

## 上报

遇到以下情况，在 PROGRESS「待你决定」追加一条，并把相关任务标为受阻：
- 超出任务卡授权范围
- 与生效决议冲突，或证据推翻了决议的前提
- 无法自行解决的阻塞

## 决议变更

决议不改原文。新决议注明「取代：D00x」，PROGRESS 中替换对应行，旧条目整段移到 `归档/决议.md`。

## 压缩与归档

- 议题已裁决：结论写入决议，议题文件移到 `归档/议题/`，PROGRESS 删除对应行。
- 任务已完成：任务卡移到 `归档/任务/`，PROGRESS 删除对应行，更新「现状」，日志记一行。

## 收工清单

1. 日志追加今天的结论（一行一条）。
2. 更新「现状」「进行中」「▶ 下一步」「卡点 / 待你决定」。
3. 已裁决的议题、已完成的任务按上面归档。
4. 两周前的日志移到 `归档/日志.md`；PROGRESS 超出上限就精简。

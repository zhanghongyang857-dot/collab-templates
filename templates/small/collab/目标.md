# 目标

项目下由总裁批准的一件件事，一个目标一张卡，新卡加在最上方。卡里的「流程」表是总裁批准的分工：每个阶段由谁做、交出什么、怎样才算通过。子任务卡在 [任务.md](任务.md)，编号 `G00x-Tn`，卡头写「阶段：n」。

阶段和目标的进度由子任务的状态推出（全部通过即该阶段通过），不在这里手写。流程表只写需要的阶段，最后一步是目标验收和汇报；各任务不单独设验收阶段。卡头「状态」只写 待批准 / 进行中 / 暂停 / 完成 / 取消；「优先」由总裁定（1 最高），「依赖」写前置目标编号。同时进行中的目标不超过 3 个。总裁批准完成的整张移到 [归档.md](归档.md)。
